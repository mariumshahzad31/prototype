### AuraEngine

#### Configuration
```python
from engine import AuraConfig, AuraEngine

config = AuraConfig(\n    user=\"aura_operator\",          # User identifier\n    learning_days=7,               # Baseline window\n    input_dim=8,                   # Feature dimensions\n    lstm_hidden_dim=64,            # LSTM hidden state size\n    lstm_layers=2,                 # Number of LSTM layers\n    isolation_forest_estimators=200,  # IF tree count\n    isolation_forest_contamination=0.01  # IF outlier rate\n)\n```\n\n#### Initialization\n```python\nengine = AuraEngine(config=config, db=db)\n```\n\n#### Feature Extraction\n```python\npacket_meta = {\n    \"timestamp\": \"2024-01-28T14:30:00\",\n    \"node\": \"S1\",                    # S1=local, S2=remote\n    \"src_ip\": \"192.168.1.100\",\n    \"dst_ip\": \"10.0.0.1\",\n    \"protocol\": \"TCP\",                # TCP, UDP, ICMP, etc.\n    \"bytes_sent\": 5000,\n    \"bytes_recv\": 2000\n}\n\nfeatures = AuraEngine.extract_features(packet_meta)\n# Returns: np.array of shape (8,) with normalized features\n```\n\n#### Scoring Events\n```python\nanomalY_score, is_anomaly = engine.score_event(packet_meta)\n# Returns: (float 0.0-1.0, bool)\n# anomaly_score > 0.2 = flagged as anomaly (configurable)\n```\n\n#### Training Profile\n```python\nhistorical_events = db.recent_events(limit=10000)\nprofile_path = engine.train_profile(historical_events)\n# Trains CNN, LSTM, IF models and saves to:\n# profiles/aura_operator_profile.h5\n```\n\n#### Model Persistence\n```python\nengine._save_profile()      # Persist .h5 file\nengine._load_profile()      # Load from disk\nengine.ensure_profile_loaded()  # Auto-load if needed\n```\n\n---\n\n### Database API\n\n#### Connection\n```python\nfrom database import Database\n\ndb = Database()  # Auto-creates aura.db if db.upsert_device(\n    user_id=user_id,\n    name=\"Local Gateway\",\n    node_label=\"S1\",\n    status=\"online\"  # online/offline\n)\n```\n\n#### Event Insertion\n```python\nevent_id = bytes_sent=5000,\n    bytes_recv=2000,\n    is_anomaly=False,\n    anomaly_score=0.15,\n    raw_features_json=json.dumps(packet_meta)\n)\n```\n\n#### Alert Creation\n```python\nalert_id = db.insert_alert(\n    user_id=user_id,\n    device_id=device_id,\n    event_id=event_id,\n    severity=\"HIGH\",  # HIGH, MEDIUM, LOW\n    title=\"Suspicious Login Attempt\",\n    message=\"Login from  'timestamp': str,              # ISO format\n    'source_ip': str,              # e.g., \"192.168.1.100\"\n    'dest_ip': str,                # e.g., \"10.0.0.1\"\n    'protocol': str,               # TCP, UDP, ICMP\n    'bytes_sent': int,\n    'bytes_recv': int,\n    'is_anomaly': bool,            # 0=normal, 1=anomaly\n    'anomaly_score': float,        # 0.0-1.0\n    'raw_features_json': str       # Original packet metadata\n}\n```\n\n### Alert Record\n```python\n{\n    'id': int,\n    'user_id': int,\n    'device_id': int,\n    'event_id': int,               # FK to events\n    'created_at': str,             # ISO format\n    'severity': str,               # HIGH, MEDIUM, LOW\n    'title': str,                  # Alert title\n    'message': str,                # Raw description\n    'explained_message': str,      # LLM-powered explanation\n    'resolved': bool               # 0=open, 1=resolved\n}\n```\n\n### Firewall Action Record\n```python\n{\n    'id': int,\n    'user_id': int,\n    'device_id': int,\n    'event_id': int,               # FK to events\n    'created_at': str,             # ISO format\n    'action': str,                 # block_ip, allow, log_only\n    'rule_ref': str                # Rule identifier\n}\n```\n\n---\n\n## 🔄 Workflow: Learning Phase\n\n1. **Data Collection** (7 days)\n   ```python\n   # Raw network traffic → events table\n   for packet in network_stream:\n       event = {\n           'timestamp': now(),\n           'src_ip': packet.src,\n           'protocol': packet.protocol,\n           'bytes_sent': packet.size,\n           'is_anomaly': False  # Assume normal during learning\n       }\n       db.insert_event(...)\n   ```\n\n2. **Feature Extraction**\n   ```python\n   features = AuraEngine.extract_features(packet_meta)\n   # Converts raw packet → 8D numeric vector\n   ```\n\n3. **Model Training**\n   ```python\n   events = db.recent_events(limit=10000)\n   profile_path = engine.train_profile(events)\n   # Trains CNN, LSTM, IF on baseline\n   ```\n\n4. **Profile Persistence**\n   ```python\n   engine._save_profile()\n   # Saves weights to profiles/aura_operator_profile.h5\n   ```\n\n---\n\n## 🚨 Workflow: Defense Phase\n\n1. **Load Profile**\n   ```python\n   engine.ensure_profile_loaded()\n   # Loads .h5 weights into models\n   ```\n\n2. **Score Incoming Request**\n   ```python\n   anomaly_score, is_anomaly = engine.score_event(packet_meta)\n   # Runs inference: < 10ms\n   ```\n\n3. **Decision Making**\n   ```python\n   if anomaly_score > THRESHOLD:\n       severity = \"HIGH\" if anomaly_score > 0.7 else \"MEDIUM\"\n       db.insert_alert(..., severity=severity)\n   ```\n\n4. **Firewall Action**\n   ```python\n   if is_anomaly and severity == \"HIGH\":\n       action = \"block_ip\"\n   elif is_anomaly:\n       action = \"log_only\"\n   else:\n       action = \"allow\"\n   \n   db.insert_firewall_action(..., action=action)\n   ```\n\n5. **Explanation Generation** (Optional)\n   ```python\n   if is_anomaly:\n       explanation = explainer.explain_anomaly(\n           anomaly_score=anomaly_score,\n           packet_meta=packet_meta\n       )\n       db.update_alert(alert_id, explained_message=explanation)\n   ```\n\n---\n\n## 📈 Performance Targets\n\n| Metric | Target | Actual
